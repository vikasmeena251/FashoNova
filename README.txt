# Gemini Integration Project

This project integrates Google's Gemini API for enhanced image processing capabilities.

## Setup
1. Install dependencies: `pip install -r requirements.txt`
2. Create a `.env` file with your Gemini API key: `GEMINI_API_KEY=your_key_here`

## Usage
Run the main application:
```
python main.py
```

## Services
- `gemini_service.py`: Handles Gemini API interactions
- `image_enhancement_service.py`: Processes images using Gemini

## Environment
- Python 3.x
- See `requirements.txt` for dependencies
